## Company and product context

Link Logistics Real Estate ("Link") is a leading operator of warehouses and
business parks specializing in last-mile logistics (industrial) real estate.
Established by Blackstone in 2019, its portfolio spans roughly half a billion
square feet across 3,000+ properties in 40+ markets. Link positions itself as a
digitally native industrial real estate firm: technology is treated as a
strategic advantage, not a support function.

The Technology organization grew from ~9 to 115+ people. It has shipped six+
custom applications and a proprietary integration-services layer, and operates
the **Link Data Platform** (25B+ data elements) as a systematized source of
truth. Public product examples include Property IQ (map-based "digital twin" for
assets), Clause IQ (AI lease abstraction), and Link+ (customer platform). ML and
predictive analytics support rent/asset valuation.

This role builds software for an **analytics platform** that delivers
data-driven insights to **internal stakeholders**, working with product
managers, data scientists, and business leaders.

## Role summary

A **Full Stack Software Engineer** who is both a **"player and a coach"**: writes
significant production code (leveraging AI-assisted coding tools) while guiding
and managing **contractors and interns**. Designs and builds end-to-end
applications from front-end interfaces to back-end services, integrating advanced
analytics and machine-learning outputs.

## Responsibilities

- Develop full-stack applications that deliver advanced analytics and ML insights to end users.
- Build responsive, user-friendly interfaces using modern front-end frameworks (React, Angular, or similar).
- Design and implement scalable back-end services and APIs in Python or Node.js.
- Integrate applications with data pipelines, ML models, and visualization components.
- Write production-quality code leveraging AI-assisted coding tools to accelerate development.
- Act as a technical lead for contractors and interns: guidance, code reviews, alignment with project goals.
- Ensure applications are performant, secure, and scalable across cloud environments (Azure preferred).
- Contribute to architectural decisions and advocate for best practices in full-stack engineering.
- Communicate effectively with technical and non-technical stakeholders.

## Technology signals

- Front-end: React, TypeScript, HTML/CSS, responsive design
- Back-end: Python (preferred), Node.js, RESTful APIs
- Data & integration: SQL, Databricks/Spark for distributed processing
- Prototyping: Streamlit for rapid internal dashboards

## Preparation implications

This posting suggests practice should prioritize:

- A React/TypeScript analytics UI that renders ML/analytics outputs with loading,
  empty, error, and stale states, plus interactive data visualization.
- A Python (or Node) API layer that exposes model/analytics outputs to the
  frontend with clean contracts, validation, and low-latency reads.
- Integration with data pipelines and ML outputs: provenance, freshness,
  confidence, and treating a stale/bad number as a production incident.
- System-design tradeoffs for an internal analytics platform over a large data
  platform (caching, contracts between app and data teams, Azure/Databricks).
- The "player-coach" dimension: reviewing contractor/intern code, setting
  standards, and coordinating delivery without formal management authority.
- AI-assisted engineering examples with verification, review, and rollback.
