# Health Records Search

**Level:** senior
**Time:** 45m

Design search for a health-tech records application. Clinicians need fast search over authorised patient records, while updates must become visible within a defined freshness window.

## Cover
- Establish privacy, authorisation, freshness, audit, and latency requirements
- Explain record update, indexing, and authorised query flows end to end
- Deep-dive permission filtering and index consistency
- Identify failure modes, SLOs, and rollback strategy

## Stretch
- Compare denormalised and query-time authorisation approaches
- Explain a safe reindex when the schema changes
