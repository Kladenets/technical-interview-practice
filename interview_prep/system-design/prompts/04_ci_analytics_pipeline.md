# CI Analytics Pipeline

**Level:** senior
**Time:** 40m

Design a reporting pipeline for a dev-tools CI product. It should ingest build events and provide daily reliability, duration, and failure-trend dashboards for engineering teams.

## Cover
- Clarify reporting latency, retention, correctness, tenant isolation, and query patterns
- Explain event ingestion, aggregation, storage, and dashboard query paths
- Deep-dive late events, corrections, and reproducible aggregation
- Estimate volume and address backfills, failures, and monitoring

## Stretch
- Explain how expensive ad-hoc queries are constrained without blocking useful analysis
- Include data-quality ownership and cost visibility
