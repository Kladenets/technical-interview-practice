# System Design Notes

A topic-oriented reference for system design ideas, tradeoffs, and interview practice. Notes are grouped by the reusable concept rather than by course chapter.

## Topics

Topic files will be added here as the collection grows. Each file should cover one coherent domain and link to related notes rather than duplicating them.
