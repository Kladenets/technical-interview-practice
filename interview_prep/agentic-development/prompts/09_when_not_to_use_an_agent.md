# When Not to Use an Agent

**Level:** senior
**Time:** 20m
**Context:** mongoose

A product stakeholder proposes using an AI agent for a new workflow. Explain how you would decide whether that is the wrong tool and make a recommendation that is honest about product value, engineering cost, and operational risk.

## Cover
- Describe a concrete decision workflow that compares the workflow's ambiguity, error cost, reversibility, and user expectations with deterministic alternatives
- Compare cost, latency, reliability, and maintenance burden for an agent against rules, forms, search, automation, or a conventional service
- Explain what verification and failure evidence you need before recommending an agent, and how that evidence changes after launch
- State the boundaries where you would decline agent use and how you would communicate the resulting tradeoff to a non-technical stakeholder

## Stretch
- Give an honest position on where agents create genuine leverage and where a simpler product design creates more value
